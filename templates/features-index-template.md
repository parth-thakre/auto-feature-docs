## Adding Features

Run `/save-feature` in your AI tool:

```bash
/save-feature              # Auto-suggests from git branch
/save-feature "Name"       # Explicit name
```

Creates dated docs in `docs/features/{name}/`:
- `YYYY-MM-DD.md` - First version
- `YYYY-MM-DD-v2.md` - Same-day update
- `YYYY-MM-DD-v3.md` - Another update
